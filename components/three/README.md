# components/three — мягкие 3D-объекты «Лоска»

Процедурная геометрия на `@react-three/fiber` + `three`. Никаких внешних моделей,
текстур и запросов: каждый предмет собирается из скруглённых боксов, капсул и одной
экструзии, а «мягкость» даёт фаска, а не карта нормалей.

## API

```tsx
// components/three/SoftScene.tsx — по умолчанию и именованным экспортом
export function SoftScene(props: { item: "sofa" | "carpet" | "mattress" | "other"; className?: string }): ReactElement;
export default SoftScene;

// components/three/SoftModel.tsx — только меши, без <Canvas> (можно переиспользовать)
export function SoftModel(props: { item: SoftItem; glow?: boolean }): ReactElement;

// components/BeforeAfter.tsx
export function BeforeAfterSlider(props: {
  item: "sofa" | "carpet" | "mattress" | "other";
  beforeSrc?: string;
  afterSrc?: string;
  caption?: string;
  className?: string;
}): ReactElement;
```

## Как встраивать сцену

`SoftScene` сам задаёт `width: 100%; height: 100%`. **Родитель обязан иметь высоту** —
иначе канвас будет нулевого размера:

```tsx
<div className="relative aspect-square w-full">   {/* или h-[420px], или aspect-[4/3] */}
  <SoftScene item="sofa" />
</div>
```

Сцена рассчитана на боксы примерно от 3:4 (телефон) до 16:10. Камера показывает ~3.5
мировых единицы по высоте, а масштаб модели считается от пропорций канваса, поэтому
объект не обрезается ни в узком, ни в широком контейнере. Очень широкие полосы
(16:6 и шире) технически работают, но предмет там мелкий — для них лучше не сцена, а
фото.

## Бюджет

| предмет | геометрия | треугольники |
| --- | --- | --- |
| sofa | 8 скруглённых боксов, 2 капсулы-подлокотника, 4 капсулы-ножки | **2 296** |
| carpet | PlaneGeometry 36×26 со смещением вершин + 52 ворсинки (instanced) | **2 496** |
| mattress | плита + шовный кант + 20 стёганых бугров (instanced) | **1 656** |
| other (кресло) | C-образная экструзия + 3 бокса + 4 ножки | **1 568** |

Все предметы укладываются в лимит ~6000 треугольников с запасом.

## Производительность и поведение

- `dpr={[1, 1.75]}`, `gl={{ antialias: true, alpha: true, powerPreference: "high-performance" }}`,
  `flat` (без tone mapping — иначе тёплые нейтрали уезжают в серый).
- Тени выключены. Вместо них — радиальный градиент-спрайт под объектом
  (`ContactShadow`), нарисованный в `canvas` и отданный как `CanvasTexture`. Он же
  единственный источник «приземления» предмета.
- `frameloop` переключается по `IntersectionObserver`: вне вьюпорта цикл
  останавливается. Пока не отрисован первый кадр, цикл не паркуется — иначе канвас
  ниже сгиба оставался бы пустым.
- Все кастомные `BufferGeometry` освобождаются в `useEffect`-cleanup при смене
  предмета и размонтировании; JSX-геометрии и материалы освобождает сам R3F.
- Материалы: `MeshStandardMaterial`, `roughness` 0.82–0.96, `metalness` 0.
  Палитра: диван `#E7DECD`, ковёр `#CFE3DE`, матрас `#F2EEE7`, кресло `#DFD9CE`,
  акцент `#0FB6A6` — только на маленькой подушке и (опционально) в ореоле.
- Свет: ambient + три directional (тёплый ключевой, холодный заполняющий, контровой).
  Интенсивности подобраны под физические единицы three r169 (свет делится на π),
  чтобы верхние грани не выбивались в белый.

## Движение

Покой: синусоидальное «дыхание» (±0.035 по Y) и лёгкое изменение масштаба.
Реакция на курсор: пружина с недостаточным демпфированием, максимум 6° наклона,
затухание по времени кадра (не зависит от FPS).

При `prefers-reduced-motion: reduce` — статичная поза, параллакс и покачивание
выключены, `frameloop="demand"` (один кадр вместо цикла).

## BeforeAfterSlider

- По умолчанию рисует текстиль сам: один и тот же `<pattern>` и одни и те же seed'ы
  `feTurbulence` в обеих панелях, поэтому линии ткани совпадают по шву. Панели
  сложены стопкой, верхняя («до») обрезается `clip-path: inset(...)` — отсюда
  идеальное совмещение при перетаскивании.
- «До»: затемняющая тёплая накладка, пятна с ободком (слой растекания + плотный слой
  с `feDisplacementMap`), общий сероватый каст и волокнистое зерно.
- «После»: та же ткань без пятен, светлее, с диагональным блеском.
- Если заданы и `beforeSrc`, и `afterSrc` — рендерятся два `<img>` (`object-fit:
  cover`, `loading="lazy"`, `decoding="async"`, alt по-русски), верхний обрезается тем
  же `clip-path`.
- Управление: мышь, тач и клавиатура. `role="slider"`, `aria-valuemin/max/now`,
  `aria-valuetext`, `aria-orientation`, русский `aria-label`. Стрелки — шаг 2,
  `Shift` — 10, `PageUp/PageDown` — 10, `Home/End` — края. `setPointerCapture`
  держит перетаскивание за пределами рамки; `touch-action: pan-y` оставляет
  вертикальный скролл страницы.
- Рамка: `aspect-[4/3]` на мобильном, `sm:aspect-[16/10]`, `rounded-card`,
  `border-line`, `overflow-hidden`.
- Все SVG-id префиксованы `useId()`, так что несколько слайдеров на одной странице
  не конфликтуют.

## Что проверено

- `npx tsc --noEmit` — ошибок в этих файлах нет.
- Живой рендер в dev-сервере при 1440px и 390px: все четыре предмета, контактная
  тень, ореол, оба слайдера (процедурный и с подписью), отсутствие горизонтального
  переполнения.
- Клавиатура и указатель на слайдере: ArrowRight 48→50→52, Home→0, End→100,
  PageUp с клампом в 100, нажатие в 25% → 25, перетаскивание до 80% → 80,
  после `pointerup` движение больше не меняет позицию.
- Рамка слайдера на 390px: 342×257 CSS px (4:3), фокус-ринт виден на ручке.
